SUPER POST - KING
=================

1. Giải nén file ZIP.
2. Đối chiếu mã SHA256 của hai file với SHA256.txt (PowerShell: Get-FileHash .\Super-Post-King-Setup.exe).
3. Chạy Super-Post-King-Setup.exe.
   Nếu Windows SmartScreen hiện cảnh báo do bộ cài chưa có chữ ký số, chỉ chọn "More info" > "Run anyway"
   sau khi mã SHA256 đã khớp.
4. Bộ cài tự kiểm tra và cài WebView2 cùng Google Chrome nếu máy chưa có.
5. Mở Super Post - King từ Desktop hoặc Start Menu.
6. Vào mục Thanh toán trong Tool để lấy mã máy và kích hoạt license.
7. Nếu dùng Codex/Claude/OpenClaw, vào Cài đặt > Agent & MCP và bấm "Cài kết nối AI".
   File Super-Post-Agent-Kit-*.zip chỉ dùng để cài offline, hỗ trợ IT hoặc khôi phục thủ công.
   Sau khi cài, thoát hẳn Claude khỏi khay hệ thống rồi mở lại. MCP local có tên
   "super-post-king-local"; mục Cloud MCP cùng tên sản phẩm có thể yêu cầu xác thực riêng.

Khách hàng không cần cài Python, Node.js hay thư viện lập trình.

Dữ liệu mặc định được lưu tại:
%LOCALAPPDATA%\King Automation AI\Super Post King

Không chia sẻ thư mục này vì có thể chứa cấu hình, phiên đăng nhập và dữ liệu cá nhân.

TÍNH NĂNG CHATGPT / ẢNH AI
- Cần cài Codex CLI mới nhất và chạy "codex login" bằng tài khoản ChatGPT một lần.
- Trong Super Post - King, vào Cài đặt > ChatGPT > Kiểm tra đăng nhập.
- Nếu Codex nằm ngoài PATH, nhập codex.exe/codex.cmd hoặc thư mục chứa Codex vào ô đường dẫn.
- Có thể bấm "Tự động tìm" để tool điền đường dẫn hoặc "Mở .codex" để mở thư mục cấu hình.
- Không chia sẻ tệp %USERPROFILE%\.codex\auth.json.
- Ảnh tạo xong được lưu trong uploads\ai-generated và tự điền vào cột Media.

AGENT API / MCP
- Agent Kit được đóng sẵn trong bộ cài; nút Cài đặt > Agent & MCP tự cài hoặc sửa cấu hình Claude/Codex/OpenClaw.
- Sau lần cài kết nối AI đầu tiên, mỗi bản cập nhật Super Post - King sẽ tự đồng bộ Agent Kit/MCP local đã cài.
- Tool không tự cài MCP trên máy chưa từng bấm "Cài kết nối AI".
- Agent Kit dùng thành phần bảo vệ đi kèm đúng phiên bản ứng dụng; không sửa hoặc thay thế file trong thư mục cài đặt.
- Mọi thông tin xác thực được tạo và lưu cục bộ. Không sao chép cấu hình Agent Kit giữa các máy.
- Sau khi app vừa đồng bộ Agent Kit, mở phiên agent mới để Claude/Codex/OpenClaw nạp bản MCP mới.

Không xóa thư mục dữ liệu nếu muốn giữ cấu hình, lịch đăng và phiên đăng nhập.
Website tác giả và các Tool khác: https://kingautomationai.com
